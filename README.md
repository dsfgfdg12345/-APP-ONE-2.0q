# 原生社区交友婚恋视频即时通讯双端APP源码ONE兔2.0

源码获取：ym7k.com/19840/

## 技术架构说明

客户端采用**原生开发**，Android 原生、iOS 原生，区别于 Uniapp 等跨端方案，在视频通话、相机采集、推送保活、美颜适配上面优势明显，适合社交 APP 高实时性场景。配套 PHP 后端 + MySQL 数据库，同时附带 H5 端，可用于网页访问、分享引流。
通讯层基于长连接 IM 服务，支持消息离线推送；音视频通话对接专业第三方音视频 SDK，支持美颜、滤镜、通话录制。整套源码交付包含安卓端源码、iOS 端源码、服务端源码、H5 源码，私有化部署，用户聊天数据、资料、订单自主管控，开放接口支持二次定制开发。
后台支持 RBAC 权限划分，平台管理员、客服、审核员权限隔离，内容审核、用户风控、订单财务分开管理。

## 核心功能模块

### 1. 用户档案、婚恋标签与智能匹配

用户注册后完善个人资料，上传相册、填写年龄、身高、职业、择偶要求、婚恋标签、兴趣爱好，搭建完整相亲档案。系统支持多种匹配方式：

- 同城附近人：LBS 定位，按距离排序推荐附近用户；
- 条件筛选：年龄、地域、收入、婚况、身高多维度筛选；
- 智能推荐匹配：根据择偶标签、浏览偏好算法推荐；
- 心动互配：喜欢 / 跳过模式，双向心动才解锁私信，保护隐私，降低骚扰。
支持实名认证、人脸核验开关，后台审核资料，减少虚假账号，适配婚恋相亲平台风控需求。

### 2. IM 即时通讯 + 1V1 音视频通话（核心能力）

这是 ONE 兔 2.0 的核心亮点。

- 私聊消息：文字、表情、图片、语音、短视频、位置发送，消息已读、撤回、离线推送；
- 1 对 1 语音通话、视频通话，通话过程支持美颜、滤镜；
- 消息风控：敏感词过滤、聊天记录后台留存，支持举报查看；
- 可设置私信权限：免费条数限制、会员解锁无限聊天、打招呼消耗金币。
很多婚恋平台采用 “打招呼付费、私信会员解锁” 模式，这套系统原生支持这类玩法。

### 3. 社区动态短视频板块

类似社交朋友圈，用户可以发布图文动态、短视频，添加定位、话题标签。其他用户可以点赞、评论、收藏、分享。动态支持后台审核，违规内容一键下架。
动态广场支持推荐流、附近动态，作为平台内容流量入口，提升用户打开频次与停留时长，弱化纯相亲的生硬感，偏向社区化社交。

### 4. 增值变现体系（平台盈利核心）

内置成熟的社交变现模块，主流婚恋平台商业模式全部覆盖：

- 会员套餐：月卡、季卡、年卡会员，解锁无限私信、优先推荐、去水印、访客查看；
- 金币充值：打招呼、发起视频、查看访客、解锁相册消耗金币；
- 礼物打赏：视频通话、个人主页送虚拟礼物，礼物自动分成；
- 付费置顶：个人资料、动态付费置顶，提升曝光；
- 广告管理：开屏广告、信息流广告，广告位自主配置。
钱包中心记录充值、消费、收益流水，收益支持提现申请，后台审核打款，财务明细可导出对账。

### 5. 访客、关注粉丝、黑名单体系

记录谁访问了我的主页，可设置仅会员查看访客记录；支持关注、粉丝列表，拉黑、屏蔽用户，拉黑后无法发起聊天、查看动态。配套举报功能，举报骚扰、虚假资料、违规内容，管理员后台审核封禁账号。

### 6. 后台管理、内容审核与数据统计

PC 管理后台功能覆盖全平台管控：用户管理、资料审核、动态审核、消息敏感词配置、订单充值记录、提现审核、礼物配置、会员套餐配置、广告配置。
数据看板统计新增注册、活跃用户、充值流水、通话量、动态发布量、热门用户等图表，支持报表导出。配套消息通知，推送审核结果、提现通知、心动匹配提醒。

## 适用场景

1. 垂直婚恋相亲平台：本地相亲、婚介所线上相亲 APP；
2. 同城交友平台：同城兴趣交友、约会社交；
3. 兴趣社群社交：车友圈、摄影、运动圈子社交；
4. 红娘中介平台：支持红娘账号，代推荐用户、收取服务费（可扩展）。

## 原生双端对比跨端方案优势

很多交友源码采用 Uniapp 跨端打包，开发快但音视频稳定性差，后台容易被杀进程、通话卡顿。ONE 兔 2.0 原生开发，推送保活、音视频、相机美颜、本地权限适配更好，上线上架应用商店更友好，适合打算长期运营、对通话体验要求高的社交项目；缺点是双端都需要原生开发者维护，二次开发成本高于纯跨端源码。

ONE 兔 2.0 是面向婚恋同城社交赛道的原生双端 APP 源码，以 IM 即时通讯、1v1 音视频通话为核心，融合同城匹配、婚恋档案、短视频社区、会员金币礼物整套变现体系。全套 Android+iOS 原生代码交付，搭配 PHP 后端和 H5，是婚介机构、社交创业者搭建独立婚恋交友 APP 的成熟方案。适合想要做自有品牌相亲社交平台，重视音视频通话体验、需要私有化数据部署的运营方。
